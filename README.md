# Mota Morales — Director

Sitio estático blanco y negro, inspirado en tipografía de máquina de escribir, para publicar en Netlify.

## Archivos

- `index.html`: sitio completo, sin dependencias, con seis trabajos incrustados desde Vimeo.
- `felipe-mota-morales.jpeg`: fotografía de portada, crédito de Tom Ghiorzo / cortesía de Fábula.
- `netlify.toml`: configuración de publicación.
